# ploma

**Status: seed.** `ploma` will be a Claude Code harness (plugin) for writing, validating, reviewing and formatting LaTeX academic papers: `/ploma:onboard` first, then a recommended lifecycle (brainstorm, grill, spec, write, compile, validate, review, respond, ship).

Nothing at the root is implemented yet. Start with [`BRIEF.md`](BRIEF.md). The `extraction/` folder holds the raw material the plugin is being distilled from (the previous project-bound harness, samples, references and research reports) and will be removed once ported.

Target install, once released:

```
/plugin marketplace add marcgarnica13/ploma
/plugin install ploma@ploma
```
