# Draft Fast-Track

**Lightweight workflow for exploratory drafting.** Quality threshold: 60/100 (vs 80 for the proposal). No planning needed.

## Steps

1. **Value check** -- Does this strengthen the proposal? If NO, don't draft it.
2. **Create folder** -- `mkdir -p drafts/[name]/{notes,output}` + README + SESSION_LOG.md
3. **Draft immediately** -- no plan needed. Must-haves: idea is captured, claims sane, goal documented. Not needed: full polish, perfect formatting, final citations.
4. **Log progress** -- append 2-3 lines to SESSION_LOG.md as you work
5. **Decision point** -- keep drafting, graduate into the proposal (upgrade to 80/100), or archive with brief explanation

## When to Stop (Kill Switch)

At any point: stop, archive with note ("Attempted X, hit blocker Y"), move on. No guilt -- drafting is inherently uncertain.
