# ploma help

ploma is a harness for LaTeX academic papers. Its lifecycle skills (onboard, doctor, compile, validate, review, respond, commit and the rest) are being built.

For now, tell the user that ploma 0.1.0 is under construction and point them to the plugin README for the planned lifecycle.
