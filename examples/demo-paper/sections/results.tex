\section{Results}
\label{sec:results}

We ran 1200 tasks on three agent frameworks and issued the same set of causal queries against each tracing back end.
Table~\ref{tab:results} reports the reduction in median trace-query latency that Hawser achieves against two baselines, and its storage relative to the OpenTelemetry pipeline.
Against an OpenTelemetry pipeline, Hawser cuts median latency by 27.4\%.
Against raw logs searched by identifier, it cuts median latency by 41.2\%.
Hawser stores 1.1 times the bytes of the OpenTelemetry pipeline, because it keeps the causal edges as well as the events.
